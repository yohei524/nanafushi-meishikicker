# 観察仮説メモ

このMDは「仮説を残しておく場所」。
机上の理論ではなく、実際の鑑定で検証していくための観察ポイントを蓄積する。
仮説が事例で繰り返し裏付けられたら、チェッカーの「観察フラグ機能」として実装する。

---

## 仮説のステータス区分

- **仮説**: 理論上の予測・未検証
- **観察中**: 鑑定で意識して見ている段階・事例蓄積中
- **検証済(肯定)**: 複数事例で裏付けられた
- **検証済(否定)**: 反例が出て覆された
- **保留**: 判断材料不足
